# 背单词 · 艾宾浩斯

一个纯前端的英语背单词程序：选词库 → 定计划 → 按艾宾浩斯遗忘曲线复习，进度存在本地，下次打开接着背。

**打开方式：双击 `index.html`**（Chrome / Edge / Firefox 都行，不需要装任何东西、不需要联网、不需要起服务）。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 分级词库 | 小学 2,140 词 / 初中 2,344 词 / 高中 6,219 词（含四级补充） |
| 每日计划 | 每日新词 5 / 10 / 15 / 20 / 30 词任选 |
| 学习卡 | 看单词 → 空格显示释义 → 评「认识 / 模糊 / 不认识」 |
| 艾宾浩斯复习 | 9 档间隔：10 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天 → 60 天 |
| 自动排程 | 每次打开，先把到期的复习刷完，再学新词 |
| 记忆 | 所有进度存在浏览器 localStorage，关掉再开自动续上 |
| 发音 | 点 🔊 用系统语音朗读（Web Speech API） |
| 例句 | 每个词配一句英文例句 + 中文翻译（10,380 词有例句，其中 6,564 词带中文对照） |
| 听写模式 | 听发音 / 看中文，敲出英文拼写，一轮 20 词；拼错自动打回第 1 档 |
| 错词本 | 答错（不认识 / 听写拼错）的词自动收录，可单独练习；连对 2 次自动移出 |
| 分组浏览 | 按**词性**（名/动/形/副…）、**前缀**（un- / re- / dis-…）、**后缀**（-ion / -able / -ly…）、**词根**（spect / port / dict…）分组，一键练整组 |
| 键盘操作 | 空格显示释义，`1` / `2` / `3` 分别评不认识 / 模糊 / 认识；听写时回车确认 |
| 统计 | 已学、已掌握、连续天数、正确率、复习档位分布、最近背过的词 |
| 词表浏览 | 当前词库的已学 / 未学列表 |

## 评分如何影响复习

- **认识**：升一档，间隔变长（第 1 档 10 分钟，之后 12 小时、1 天、2 天…）。
- **模糊**：档位不变，10 分钟后再考。
- **不认识**：打回第 1 档，5 分钟后再考。

连续答对 9 次即「已掌握」（间隔 60 天）。

## 听写与错词本怎么用

- **听写**：首页点「✍️ 听写」。卡片上不显示拼写，只有 🔊 和中文释义；听不懂可以点 🔊 重听，输入框里敲英文、回车判定。拼对 → 档位 +1；拼错 → 显示正确答案，打回第 1 档并进错词本。听写只从**已经背过的词**里出题。
- **错词本**：首页点「📕 错词本」。按错误次数排序，每个词带释义、例句和最近一次出错的时间；可以「练习这些词」（走普通学习卡）、「移除」单个词或清空。连续答对 2 次会自动移出。
- 三个功能共用同一套复习排程，所以听写和错词练习同样会影响艾宾浩斯档位。

## 按词根 / 词性分组怎么用

首页点「🧩 按词根 / 词性分组」，切到当前词库的分组页，四个标签页：

- **词性**：名词 n. / 动词 v. / 形容词 adj. / 副词 adv. / 介词 / 代词 / 连词 / 冠词 / 数词 / 缩写字…全部 10,703 词都有归属（词性取自 ECDICT 释义的首个标注）。
- **前缀**：un- 不 / re- 再 / dis- 分开 / in- 向内 / con- 共同 / over- 过度…只保留「剥掉前缀后剩下的是个真词」的组合，所以不会有 `republican` 这种假阳性。
- **后缀**：-ion / -ment / -ness / -able / -ly / -er…同样要求词干是真词（`action = act + ion`），-ed / -ing 这类屈折变化没有收进来。
- **词根**：spect 看 / port 搬运 / dict 说 / tain 握…先剥一层前缀再比对词根，`inspect`、`respect`、`suspect` 会落进同一组。

点开任一分组能看到该组的词（已学的标绿），下面的「练这组」直接开一轮学习卡。**分组练习不占每日新词额度**，随手练多少组都不影响今天的计划。

## 词库来源与构建

- 分级依据：教材词书（[LinXueyuanStdio/DictionaryData](https://github.com/LinXueyuanStdio/DictionaryData)）里的**小学英语 / 初中英语 / 高中英语 / 大学英语四级词汇**词书。
- 音标与中文释义：[ECDICT](https://github.com/skywind3000/ECDICT)（MIT）。
- 例句：[Tatoeba](https://tatoeba.org)（英文与中文语料，CC BY 2.0 FR）。只挑 4~14 个词的短句，优先选已有中文对照的句子；没有对照的只显示英文原句。
- 分层规则：小学词表 → 初中 = 教材初中 ∪ 小学 − 已收 → 高中 = 教材高中 ∪ 四级 − 已收，每层按词频排序，只收单词（丢弃词组、人名、带空格条目），跨层不重复。

重新构建：

```powershell
cd _build
powershell -ExecutionPolicy Bypass -File fetch-inputs.ps1   # 下载词库原始数据（约 180MB，只需一次）
node build-bank.mjs                                          # 生成 ../data/bank.js
node build-groups.mjs                                        # 生成 ../data/groups.js（分组数据）
# 例句（需要 Python，语料约 26MB，解压后较大）
python build-examples.py                                     # 生成 ../data/examples.js
cd .. ; node _build/smoke-test.cjs                           # 自测
```

## 注意

- 进度只存在**这台设备这个浏览器**里。换浏览器、清缓存、用无痕窗口都会看不到旧进度。
- 从 `file://` 直接打开即可使用；如果你把整个文件夹放进网盘同步，进度不会跟着走（它不在文件里）。
